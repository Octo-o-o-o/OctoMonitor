Heatmap Tab Proposal

把活跃节奏拆成 小时视图 和 日期视图。

这个原型把新增的 Heatmap tab 定成一个分析面板：周/月视图保持 按小时 看 burst，全年总览切到 GitHub 风格的 按日期 贡献日历。上方再提供 Input / Token / Commit 三种生成口径切换，确保同一套布局既能看交互频率，也能看成本和产出。

周 x 小时: 找高峰工时 月 x 小时: 看阶段性波动 总览 x 日期: 看 streak 和周期 颜色按当前视图分位数映射
Interaction Model
1 个新 tab，2 组切换，3 种图。

避免把热力图塞进 Usage 或 Commits 里，独立成页后可以承载 hover 详情、峰值分析和后续 drill-down。

Why Not One Chart
小时和日期是两种阅读任务。

周/月需要定位具体时段，总览需要看长期节奏。强行统一成一种矩阵会牺牲其中一边的可读性。

Design Tradeoff
周/月保留小时粒度，是为了快速回答“什么时候最忙”。 总览改成按日期，是为了快速回答“整体是否稳定、是否有 streak、哪些周异常”。
